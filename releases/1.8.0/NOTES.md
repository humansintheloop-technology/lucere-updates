# Lucere v1.8.0

Update with one tap

New versions of Lucere now install with a tap on Update, right on Today, and Undo on the Trust page takes one back out. Each is checked and tested on a copy of your space first, and nothing changes until you say yes.

- Channel: stable
- Applies to: v1.7.5
- Essential: no
- Changes sending: no
- New capabilities: Lets your page install an update, or undo one, only after you tap Update or Undo and then Yes. It can publish only your own page. (Declare artifact: {} beside what the page already has.)
